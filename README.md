# 🐾 ONG Palmas e Patas — Website Institucional

Este repositório contém o código-fonte do website institucional da ONG fictícia **Palmas e Patas**, dedicada à causa da proteção e adoção animal. O projeto é focado na aplicação de boas práticas de HTML5 semântico, acessibilidade e estruturação web.

## 📁 Estrutura Atual do Site
- `index.html` — Página inicial com apresentação da ONG, missão, visão, valores e informações institucionais.
- `projetos.html` — Página de projetos, campanhas, formas de doação e voluntariado.
- `cadastro.html` — Página com formulário de cadastro para novos voluntários.
- `index.css` — Estilização específica da página inicial.
- `projetos.css` — Estilização específica da página de projetos.
- `cadastro.css` — Estilização específica da página de cadastro e de seu formulário.
- `styles.css` — Estilização global compartilhada entre as páginas, como cabeçalho, navegação e rodapé.
- `scripts.js` — Reservado para futuras funcionalidades e interações em JavaScript.
